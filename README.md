# Click Hints

Geode-мод для Geometry Dash 2.2081 (Geode v5.0.0). Помогает выучить уровень: записывает твои клики и показывает их лентой внизу экрана за несколько блоков до нужного места.

## Как пользоваться

1. Играй уровень как обычно (лучше в практике). Мод записывает каждое нажатие и отпускание, привязывая их к позиции в уровне.
2. В следующих попытках внизу экрана видна лента:
   - слева белая линия «сейчас»;
   - зелёная метка: нажать, красная: отпустить;
   - зелёная полоса между ними: держать;
   - ближайший клик рисуется толще.
3. Когда уровень выучен, нажми **H**, и подсказки исчезнут. Нажми ещё раз, и они вернутся.
4. Когда есть хороший проход, выключи в настройках «Записывать клики», чтобы неудачная попытка его не перезаписала.

Записи лежат в папке сохранений мода (`hints/<ID уровня>.txt`). Один файл на уровень.

## Как работает запись

Каждая попытка заменяет клики только на том участке, который она прошла (от старта или чекпоинта до точки смерти). Слишком короткие попытки игнорируются (настройка «Минимальная длина попытки»).

## Сборка

Нужны: Geode SDK и Geode CLI, Visual Studio с C++ (для Windows), CMake, переменная `GEODE_SDK`.

```
geode build
```

Готовый файл `me.click-hints.geode` положи в папку `geode/mods` игры.

Перед сборкой замени в `mod.json` поля `id` (формат `ник.название`) и `developer` на свои.

## Известные ограничения первой версии

- Записывается только первый игрок (режим двух игроков пока не поддержан).
- Подсказки привязаны к позиции по X, поэтому уровни с обратными порталами и зеркалом могут показываться неточно.
- Если версия Geode у тебя другая, поменяй `geode` в `mod.json` на точную установленную.
